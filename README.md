# High-Low Number Guessing Game 
## Project Overview
This is a number guessing game, where the user sets the upper and lower bounds, then guesses a randomly generated, secret number in between.
The initial pseudocode and program were created in Python using the platforms Thonny and PyCharm, respectively. 
The pseudocode was from my introductory scripting class, but the finished code was created independently.
I know there are ways to refine, improve, and optimize the coding flow; however, I wanted to share what I have so far. 
This is by no means a complex game, nor do I aim to promote it as such. This is merely my first venture into coding with a functional program. 

## Features
- Allows users to select upper and lower numerical bounds
- Randomly generates a secret number within the selected bounds
- Validates numerical ranges and guesses
- Provides feedback as to whether the guess is too low or too high
- Allows for players to play multiple rounds
- Accepts a variety of capitalizations of "yes" when restarting the game

## How to Run
1. Install Python 3
2. Download the .py file
3. Open the file in any IDE or run it from a terminal using Python
4. Follow the prompts to play

## Limitations
- Only accepts numerical values
- Repetitive code
- Does not count the number of guesses it took to get the secret number
